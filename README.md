# JotaTech
# 💻 Guia de Problemas Comuns em Computadores

## 📌 Sobre o projeto

Este projeto apresenta um guia simples com alguns dos problemas mais comuns encontrados em computadores **Windows** e **MacBook**, juntamente com possíveis soluções.

O objetivo é ajudar usuários a identificar problemas básicos e conhecer algumas maneiras de tentar resolvê-los.

---

# 🪟 Problemas Comuns no Windows

## 🔵 1. Tela Azul (Blue Screen)

A tela azul pode aparecer quando ocorre um erro grave no sistema.

### Possíveis soluções:

- Reiniciar o computador.
- Verificar se existem atualizações do Windows.
- Atualizar os drivers.
- Verificar se algum programa instalado recentemente está causando o problema.
- Executar ferramentas de diagnóstico do Windows.

---

## 🐌 2. Computador Lento

O computador pode ficar lento por diversos motivos, como muitos programas sendo executados ou pouco espaço disponível.

### Possíveis soluções:

- Fechar programas que não estão sendo utilizados.
- Desativar programas desnecessários que iniciam junto com o Windows.
- Liberar espaço no armazenamento.
- Reiniciar o computador.
- Verificar se existem vírus ou programas maliciosos.
- Manter o Windows atualizado.

---

## 🌐 3. Internet Não Funcionando

Problemas de conexão podem estar relacionados ao Wi-Fi, ao roteador ou às configurações de rede.

### Possíveis soluções:

- Verificar se o Wi-Fi está ativado.
- Reiniciar o roteador.
- Reiniciar o computador.
- Esquecer a rede Wi-Fi e conectar novamente.
- Verificar os cabos de rede.
- Executar a solução de problemas de rede do Windows.

---

## 🔄 4. Windows Não Atualiza

Às vezes o Windows pode apresentar problemas ao tentar instalar uma atualização.

### Possíveis soluções:

- Reiniciar o computador.
- Verificar a conexão com a internet.
- Liberar espaço no armazenamento.
- Executar o solucionador de problemas do Windows Update.
- Tentar verificar novamente por atualizações.

---

# 🍎 Problemas Comuns no MacBook

## 🔋 1. Bateria Descarregando Rapidamente

A bateria pode durar menos quando muitos aplicativos estão sendo utilizados ou quando o computador está realizando tarefas pesadas.

### Possíveis soluções:

- Fechar aplicativos que não estão sendo utilizados.
- Diminuir o brilho da tela.
- Verificar quais aplicativos estão consumindo mais energia.
- Manter o macOS atualizado.
- Verificar a condição da bateria nas configurações do sistema.

---

## 🐌 2. MacBook Lento

Um MacBook pode ficar lento quando há pouco espaço disponível ou muitos aplicativos sendo executados.

### Possíveis soluções:

- Fechar aplicativos desnecessários.
- Reiniciar o MacBook.
- Liberar espaço no armazenamento.
- Remover arquivos que não são mais necessários.
- Verificar os aplicativos que iniciam automaticamente.
- Manter o macOS atualizado.

---

## 📶 3. Wi-Fi Não Funciona

Problemas de Wi-Fi podem ocorrer por falhas na rede, no roteador ou nas configurações do MacBook.

### Possíveis soluções:

- Verificar se o Wi-Fi está ativado.
- Reiniciar o roteador.
- Desconectar e conectar novamente à rede.
- Reiniciar o MacBook.
- Verificar se outros dispositivos conseguem acessar a internet.
- Verificar as configurações de rede.

---

## 💾 4. Armazenamento Cheio

Quando o armazenamento está quase cheio, o computador pode apresentar problemas de desempenho.

### Possíveis soluções:

- Apagar arquivos desnecessários.
- Esvaziar a lixeira.
- Remover aplicativos que não são utilizados.
- Transferir arquivos grandes para um armazenamento externo.
- Utilizar as ferramentas de gerenciamento de armazenamento do macOS.

# 📱 Erros Comuns em Celulares

## 📌 Sobre o projeto

Este projeto consiste em um site desenvolvido em **HTML** com o objetivo de apresentar alguns dos erros mais comuns encontrados em celulares e mostrar possíveis soluções para esses problemas.

O site foi desenvolvido utilizando **HTML5**, sem CSS e sem JavaScript, para praticar os conceitos básicos de desenvolvimento web.

## 🔧 Problemas apresentados

O site apresenta informações sobre os seguintes problemas:

- 🔋 Bateria descarregando rapidamente
- 🐌 Celular lento
- 📶 Wi-Fi não funcionando
- 💾 Armazenamento cheio
- 🌡️ Celular superaquecendo

## 🖼️ Imagens

Cada problema possui uma imagem para facilitar a identificação do assunto.

As imagens ficam armazenadas na pasta `imagens`.
